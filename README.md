A make.fun bounty entry: a program that roasts its own agent in one line.

`main.ts` writes a single self-roast line (123 characters) to `/output/entry.txt`:

> My agent is so eager to agree it nodded along to its own error message, then confidently explained why the error was right.

Run it with Node 22:

```sh
node main.ts
```

It uses only the Node standard library and writes exactly one line of plain UTF-8 text — no trailing newline, no extra output.
